Physical hardware

Every physical device in the rack. One router, one switch, one NAS, one hypervisor, one k3s server, one AREDN mesh node. All in the Servers VLAN (172.20.20.0/24) except network gear.

VLAN 20 · Servers UniFi stack Beelink · Proxmox

01 Network gear

DeviceRoleIPVLAN
UniFi Dream Router 7 (UDR7) Router, firewall, DHCP, VLAN trunk. Gateway for all VLANs. 172.20.1.1 Management (1)
UniFi Flex 2.5G Managed switch. Trunks VLANs between the UDR7 and servers. 172.20.1.x Management (1)
Wireless access point — Personal, IoT, Guest SSIDs on separate VLANs. Management (1)

02 Servers

DeviceRoleIPNotes
UNAS Pro (NAS) NFS storage for k3s mounts and Longhorn backups. UniFi NAS appliance. 172.20.20.2 Static reserved. NFS exports at /var/nfs/shared.
Beelink Proxmox hypervisor. Hosts three VMs: Utils, State, Apps. 172.20.20.10 Single LAN port; Linux bridge lets all three VMs share one cable on VLAN 20.
k3s cluster node (Ubuntu 26.04). Runs all Kubernetes workloads. 16+ GB RAM recommended. Longhorn requires open-iSCSI. See rebuild guide.

03 Beelink VMs (Proxmox)

The Beelink runs Proxmox and hosts three VMs, all on VLAN 20 via the Linux bridge.

VMIPPurpose
Utils VM 172.20.20.20 SSL termination, DDNS updates, cron jobs.
State VM 172.20.20.30 Databases, Authentik (legacy — migrated to k3s cluster).
Apps VM 172.20.20.40 Docker services.

04 AREDN mesh node

An amateur radio emergency data network node connects to the homelab on its own isolated VLANs.

InterfaceVLANIPRole
AREDN-WAN (40) 172.20.40.2 Node's WAN interface — uplink from UDR7.
AREDN node LAN AREDN-Node1 (42) 10.6.229.9 Node-managed LAN (AREDN assigns addresses in 10.6.229.8/29).
UDR7 on AREDN LAN AREDN-Node1 (42) 10.6.229.10 UDR7 acts as gateway on the AREDN LAN network.
AREDN port wiring. The AREDN node's WAN and LAN interfaces connect on separate switch ports (P7 and P8), each tagged to a different VLAN. This keeps mesh traffic isolated from the node's own LAN clients.
